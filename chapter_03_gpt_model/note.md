# Dropout
- dropout은 뉴런, 토큰 간의 관계에 과도한 의존을 막아서, 학습 데이터에 없는 입력이 들어와도 잘 추론할 수 있도록 하기 위함. (generalization을 높인다.)
- 무작위로 일부 가중치 값을 0으로 만들어서 과대적합을 막는다. 
- 학습 데이터가 방대한 경우에는 굳이 하지 않아도 된다.

# Layer Norm
- 신경망 층의 활성화(출력)을 평균이 0, 분산이 1이 되도록 함.
- 심층 신경망에서는 훈련 시에 그레디언트 소실, 폭주 문제로 인해서 가중치 조정이 어렵다.
- 이로 인해, 훈련 중에 loss를 최소로 하는 파라미터를 찾기 어려움.
- 정규화를 하면 찾기 용이하다. 

# residual (short cut)
- x + F(x) 
- layer 변환을 거치는 과정에서 입력이 그대로 이어지는 우회 경로가 존재하도록 함.
- 역전파를 거치면서 그레디언트가 점점 작아진다. (그레디언트 소실 문제)
- 이를 이용하면, 중간 layer의 미분 값이 아주 작아지더라도 layer 통과 후 그레디언트가 완전히 사라지는 상황을 완화할 수 있다.
- layer가 많은 모델에서 더욱 유리하다. 

# Feed Forward Network
- linear 함수를 거치고, 비선형 함수(GELU)를 거치고, linear 함수를 거치는 과정
- 선형 함수의 경우, 여러 함수를 거쳐 조합해도 어차피 선형이다. 즉, 고정된 규칙을 따르게 된다. 
- 비선형의 경우, 조합하여 다양한 복잡한 함수나 경계를 표현할 수 있다.
- 복잡한 데이터 입력 관계를, 구분하기 쉬운 표현으로 학습해서 변환 가능

**임베딩 차원 확장하는 방식**
- 가중치 행렬을 이용한다. y = Wx + b
- x = [1,3] 이고, 가중치 행렬 W = [3,12] 라면, 임베딩 차원은 [1,12] 가 된다.
